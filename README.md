## ⚙️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/vivekchaudhary7904/devops-portfolio.git
```

### 2. Enter the project directory

```bash
cd devops-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local URL shown by Vite, usually:

```text
http://localhost:5173
```

---

## 🏗️ Build for Production

Create a production build:

```bash
npm run build
```

Vite generates the production files inside:

```text
dist/
```

To preview the production build locally:

```bash
npm run preview
```

## ☁️ AWS Deployment

One of my goals with this project is to use it as a practical **AWS + DevOps hands-on project**.

Planned deployment architecture:

```text
Developer
    │
    ▼
GitHub Repository
    │
    ▼
React + Vite Build
    │
    ▼
AWS S3
    │
    ▼
Static Website
```

### Planned AWS Services

* Amazon S3 — Static website hosting
* IAM — Access management
* CloudFront — CDN
* Route 53 — Domain management
* ACM — HTTPS/SSL certificate

Later, I plan to improve the project by implementing **CI/CD automation** so that changes pushed to GitHub can automatically be deployed.
